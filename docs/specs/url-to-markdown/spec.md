# URL to Markdown

웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 변환해 보여 주고, 복사·다운로드하거나 프롬프트와 함께 ChatGPT·Claude로 바로 넘기는 서비스입니다.

## 승인된 화면

[prototype.html](prototype.html)이 승인된 화면 구성과 동작의 기준입니다. 변환기 한 화면과 Default, Loading, Result, Long article, Invalid URL, Fetch failed, No content 상태가 들어 있습니다. 배치, 위계, 오류 문구, 안내 문구는 이 파일을 따릅니다. 실제 변환, 다운로드, 클립보드, 외부 열기는 더미 동작이므로 동작 규칙은 아래 본문을 따르고, 프로토타입은 참고용이며 운영 코드가 아닙니다.

## 사용자 결과

- URL 하나로 광고와 탐색 요소가 빠진 깨끗한 본문 Markdown을 얻습니다.
- 그 Markdown을 파일, 클립보드, LLM 대화 중 원하는 곳으로 한 번에 보냅니다.

## 범위

### 1. 입력
- URL 입력란에 주소를 붙여넣고 변환을 실행합니다.
- 실행 버튼의 이름은 "변환하기"입니다.
- 입력란에 글자가 있으면 입력란 안쪽 오른쪽 끝에 X(지우기) 버튼이 나타납니다. 입력란이 비면 X도 사라집니다. X를 누르면 입력란과 결과, 오류 표시를 모두 처음 상태로 되돌립니다.
- `http`와 `https` 주소만 받습니다. 그 밖의 값은 변환하지 않고 입력 오류로 안내합니다.

### 2. 변환
- 본문 추출과 Markdown 변환에는 `defuddle` 라이브러리를 사용합니다(필수 요구).
- 외부 페이지는 브라우저가 아니라 서버가 가져와 변환합니다.
- 변환하는 동안 진행 중임을 보여 줍니다.

### 3. 결과 확인
- 헤더에 페이지 제목과 저자를 보여 줍니다. 저자를 알 수 없으면 저자 줄만 생략합니다.
- 그 아래에 Markdown을 렌더링한 결과를 보여 줍니다.

### 4. 내보내기
- **복사하기**: 변환된 Markdown 본문만 클립보드에 복사합니다. 프롬프트는 붙이지 않습니다.
- **.md 다운로드**: 변환된 Markdown 본문만 파일로 저장합니다. 파일명은 페이지 제목에서 만듭니다.
- **ChatGPT로 열기 / Claude로 열기**: 선택한 프롬프트가 있으면 본문 앞에 붙여 `프롬프트 + 빈 줄 + 본문` 순서로 전달합니다. 전달 방식은 아래 합의한 하이브리드를 따릅니다.

### 5. 프롬프트
- 프리셋은 `요약해줘`, `한국어로 번역해줘`, `쉽게 설명해줘` 세 가지이고, 별도로 `직접 입력` 선택지가 있습니다.
- 프롬프트는 선택 사항입니다. 아무것도 고르지 않으면 본문만 전달합니다.
- `직접 입력`을 고르면 텍스트 입력란이 나타납니다. 입력값은 저장하지 않고 한 번 쓰고 끝납니다(새로고침하면 사라집니다).
- 프롬프트는 ChatGPT·Claude로 열기에만 적용됩니다.

### 6. 다크모드
- 다크모드 토글을 제공합니다.

## 합의한 결정

**LLM으로 넘기는 방식은 하이브리드입니다.** 프롬프트와 본문을 합친 길이가 URL 길이 제한 이내면 새 대화에 미리 채워서 엽니다. 넘으면 전체 텍스트(프롬프트 포함)를 클립보드에 복사하고 새 대화를 연 뒤 붙여넣으라고 안내합니다.

- 이유: 짧은 글은 한 번에 넘어가고, 긴 글도 내용이 조용히 잘리지 않습니다.
- 기각: 항상 클립보드(매번 붙여넣기 필요), 항상 URL(긴 글이 조용히 유실됨).

## 수용 기준

1. 유효한 기사 URL을 넣고 변환하면 제목, 저자(있을 때), 렌더링된 Markdown이 보입니다.
2. 입력란에 글자가 있을 때만 X 버튼이 보이고, 누르면 입력, 결과, 오류가 모두 사라집니다.
3. 복사하기를 누르면 클립보드에 본문 Markdown이 들어가고, 복사됐다는 피드백이 보입니다.
4. .md 다운로드를 누르면 본문 Markdown이 담긴 `.md` 파일이 저장됩니다.
5. 프리셋을 고르고 ChatGPT 또는 Claude로 열면, 전달되는 텍스트가 `프롬프트 + 빈 줄 + 본문` 순서입니다. 프롬프트를 고르지 않으면 본문만 전달됩니다.
6. `직접 입력`을 고르면 입력란이 나타나고, 거기에 쓴 문장이 프롬프트로 전달됩니다. 새로고침 후에는 남아 있지 않습니다.
7. 합친 텍스트가 길이 제한 이내면 새 대화가 미리 채워진 채 열립니다. 넘으면 클립보드에 전체 텍스트가 복사되고, 안내 문구와 함께 새 대화가 열립니다.
8. 잘못된 주소, 접근 실패(네트워크 오류·4xx·5xx), 본문을 추출하지 못한 경우에 각각 이유가 보이는 오류 메시지가 나오고, 다시 시도할 수 있습니다.
9. 다크모드 토글로 화면이 라이트와 다크 사이를 오갑니다.
10. 좁은 화면에서도 입력, 결과, 내보내기 동작이 모두 사용 가능합니다.

## 제약과 근거

- 본문 변환은 `defuddle`로 합니다. 요구 사항이며, `defuddle@0.19.5`의 `defuddle/node`에 HTML과 URL을 넘기고 `{ markdown: true }`를 주면 `content`, `title`, `author`가 나오는 것을 scratch 복사본에서 Wikipedia 문서로 확인했습니다.
- 브라우저에서 임의의 외부 URL을 직접 가져오면 CORS에 막히므로 가져오기는 서버에서 합니다.
- UI는 `docs/decisions/ui-composition.md`를 따릅니다. 일반 UI는 shadcn 구성을 쓰고, 로딩·빈 상태·오류 상태를 정상 화면과 함께 설계합니다.

## 가정 (바꾸고 싶으면 알려 주세요)

- 다크모드는 처음에는 시스템 설정을 따르고, 토글로 바꾼 선택은 이 브라우저에 기억합니다.
- 프롬프트를 고르지 않은 상태가 기본값입니다.
- 복사하기와 다운로드에는 프롬프트를 붙이지 않습니다.
- 다운로드 파일명은 페이지 제목에서 만들고, 제목이 없으면 기본 이름을 씁니다.
- URL 길이 제한의 기준값은 구현에서 정합니다. 보수적으로 잡아 미리 채우기가 확실히 열리는 쪽에 둡니다.

## 범위 밖

- 로그인이 필요한 페이지, 자바스크립트로 그려지는 페이지의 본문 추출 보장.
- 변환 결과나 프롬프트의 서버 저장, 변환 기록, 계정.
- 서버가 가져오는 주소에 대한 사설망 접근 차단 같은 보안 하드닝(학습용 템플릿 예산상 요구하지 않음).
- ChatGPT·Claude 외 다른 LLM 서비스.

## 보류

- 없음.

## 남은 위험

- `chatgpt.com`과 `claude.ai`의 새 대화 미리 채우기 URL 파라미터가 지금도 동작하는지는 로그인이 필요해 확인하지 못했습니다. 동작하지 않으면 미리 채우기 경로가 비어 열릴 수 있으므로, 구현에서 실제로 열어 확인해야 합니다. 동작하지 않을 때의 대안은 항상 클립보드 방식입니다.
- `defuddle`은 페이지에 따라 저자를 비워 둘 수 있고, 일부 페이지는 본문이 비거나 일부만 나올 수 있습니다.
- 서버가 임의의 URL을 가져오므로 오용될 여지가 있습니다(범위 밖으로 둠).
